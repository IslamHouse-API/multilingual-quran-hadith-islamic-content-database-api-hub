# 📌 الهدف

يخدم هذا المستودع **المطورين والباحثين والمؤسسات وفرق المنتجات حول العالم** الذين يحتاجون إلى نقطة مرجعية موحدة للوصول إلى محتوى إسلامي أصيل ومتعدد اللغات من خلال منصات وواجهات رسمية.

ويجمع الوصول إلى:

- **IslamHouse.com** ← الكتب، المقالات، الفتاوى، الصوتيات، المرئيات، المؤلفون، الناشرون، التصنيفات وغيرها من الموارد الإسلامية.
- **QuranEnc.com** ← ترجمات معاني القرآن، التفسير، بيانات السور والآيات، بيانات المترجم والإصدار.
- **HadeethEnc.com** ← ترجمات الأحاديث الموثقة، والشروح، والتصنيفات الموضوعية.

**الوصول إلى واجهات API مجاني.** أما إعادة استخدام المحتوى أو إعادة توزيعه أو تضمينه داخل التطبيقات دون اتصال بالإنترنت أو استخدامه تجاريًا أو غير ذلك من أوجه الاستخدام، فيخضع لشروط المحتوى وحقوق أصحاب الحقوق ذات الصلة.

# 🎯 لماذا أُنشئت هذه البوابة؟

غالبًا ما يواجه المطورون أربع مشكلات رئيسية عند تطوير التطبيقات الإسلامية:

1. **تشتت المصادر** — بيانات القرآن والحديث والكتب والصوتيات والمواد متعددة اللغات موزعة على خدمات متعددة.
2. **جودة المصدر** — قد تفتقر مجموعات البيانات غير الرسمية إلى معلومات المصدر أو المترجم أو بيانات الإصدار.
3. **اكتشاف اللغات** — قد يصعب معرفة اللغات المدعومة بصورة موحدة ودقيقة.
4. **وضوح الحقوق** — الوصول إلى API لا يعني تلقائيًا امتلاك حقوق المحتوى أو حرية استخدامه دون شروط.

توفر هذه البوابة نقطة مرجعية واحدة وسهلة للمطورين لاكتشاف الواجهات الرسمية، وأنواع المحتوى، ودليل اللغات المعتمدة، وإرشادات التكامل، ومعلومات الحقوق.

# 🌍 تغطية اللغات

يعتمد هذا المستودع **الدليل المعتمد المكون من 147 لغة** والمقدم من المشروع بوصفه المرجع الرسمي للغات.

> [!NOTE]
> يوضح الدليل التالي اللغات المعتمدة وبيانات ISO المستخدمة في المشروع. ولا يعني ذلك أن جميع المنصات أو جميع أنواع المحتوى متوفرة في جميع اللغات الـ147. يختلف التوفر الفعلي حسب المنصة ونوع المحتوى والترجمة والإصدار.

**حقول الدليل:**

- **الاسم الأصلي** — الاسم المعتمد باللغة الأصلية.
- **رمز ISO** — رمز اللغة المعتمد في الدليل.
- **معيار ISO** — إصدار معيار ISO 639 المستخدم للرمز.
- **الاسم العربي** — الاسم العربي المعتمد للغة.
- **الاسم الإنجليزي** — الاسم الإنجليزي المعتمد للغة.

# ⚖️ استخدام المحتوى والحقوق

## 1. ترخيص الكود مقابل حقوق المحتوى

| العنصر | وضع الترخيص / الحقوق |
|---|---|
| الكود المصدري للمستودع | **ترخيص MIT** |
| الأمثلة التقنية الأصلية وتوثيق المستودع | **ترخيص MIT** ما لم يذكر ملف معين خلاف ذلك |
| ترجمات معاني القرآن والتفسير | تخضع بصورة مستقلة لشروط QuranEnc أو الناشر أو المترجم أو صاحب الحق المعني |

| مواد الأطراف الثالثة | تخضع لحقوق وشروط صاحب الحق المعني |

## 2. النسبة إلى المصدر

عند استخدام المحتوى، احفظ وأظهر بيانات النسبة ذات الصلة متى ما كانت متوفرة، بما في ذلك:

- المنصة المصدر: **IslamHouse** أو **QuranEnc** أو **HadeethEnc**.
- المترجم أو مصدر الترجمة.
- المؤلف أو العالم.
- المراجع أو المشرف.
- الناشر أو المؤسسة.
- القارئ أو المقرئ في المحتوى الصوتي.
- بيانات النسخة أو الإصدار.

## 3. التطبيقات التجارية والمشروعات المدرة للدخل

يمكن السماح باستخدام المحتوى داخل التطبيقات التجارية أو المدعومة بالإعلانات أو الاشتراكات أو غيرها من نماذج الإيرادات **إذا كانت حقوق المحتوى المعني تسمح بذلك**.

ولا يجوز تفسير ترخيص MIT الخاص بهذا المستودع على أنه إذن تجاري عام يشمل كل مادة متاحة عبر المنصات المشار إليها.

إذا كنت تحتاج إلى تأكيد رسمي لمشروع تجاري فتواصل عبر:

📧 **admin@islamhouse.com**

## 4. التخزين دون اتصال، والتخزين المؤقت، والتضمين

قد يسمح لبعض المواد بالتخزين دون اتصال بالإنترنت أو التخزين المؤقت في الخادم أو تضمينها داخل التطبيق أو إنشاء نسخة مرآة منها أو إعادة توزيع مجموعات البيانات، ولكن الإذن الدقيق يعتمد على المصدر وصاحب الحق.

تحقق من الشروط المطبقة قبل إطلاق مشروع يتضمن:

- تضمين المحتوى داخل حزمة التطبيق.
- الاحتفاظ بنسخة محلية طويلة الأجل.
- إعادة نشر مجموعة بيانات كبيرة.
- تشغيل نسخة مرآة أو API مشتقة.
- إعادة توزيع الملفات القابلة للتحميل.
- توزيع المحتوى من خلال مؤسسة أو موزع خارجي.

## 5. الذكاء الاصطناعي وRAG والبحث والتعلم الآلي

يمكن استخدام واجهات API لبناء تطبيقات البحث والتعليم والذكاء الاصطناعي وأنظمة الاسترجاع، بشرط مراعاة الحقوق التي تحكم المحتوى الأصلي.

ولا ينبغي افتراض أن إذن استرجاع المحتوى أو فهرسته أو البحث فيه أو عرضه يمنح تلقائيًا الحق في:

- تدريب نموذج أو إجراء Fine-tuning على المحتوى.
- نشر أو إعادة توزيع Dataset مخصصة للتدريب.
- حذف بيانات المصدر أو النسبة.
- عرض محتوى مولّد على أنه اقتباس حرفي من المصدر الأصلي.
- نشر نص ديني معدل على أنه النص الأصلي.

إذا تجاوز استخدام الذكاء الاصطناعي البحث أو الفهرسة أو الاسترجاع أو العرض المعتاد، فينبغي طلب توضيح بشأن الحقوق قبل النشر.

## 6. سلامة المحتوى

يجب التعامل مع النصوص الدينية والترجمات والشروح والمواد الأصلية بأمانة ودقة.

وتُقبل العمليات التقنية مثل التنسيق، وترقيم الصفحات، والفهرسة، والبحث، والتخزين المؤقت، وتصميم واجهة المستخدم، بشرط ألا تؤدي إلى تغيير المصدر أو المعنى أو تحريفهما أو إخفائهما.

ويجب التمييز بوضوح بين الملخصات أو التعليقات أو الترجمات أو المخرجات التي يولدها الذكاء الاصطناعي وبين المحتوى الأصلي.

## 7. مواد الأطراف الثالثة

قد تكون بعض المواد المتاحة عبر المنصات صادرة عن مترجمين أو ناشرين أو مؤسسات أو مؤلفين أو قراء أو أطراف أخرى.

# ❓ الأسئلة الشائعة

### هل الوصول إلى واجهات API مجاني؟

نعم. الواجهات المشار إليها متاحة للوصول المجاني. لكن **مجانية الوصول إلى API لا تعني تلقائيًا أن كل مادة مرخصة لكل صور إعادة الاستخدام أو إعادة التوزيع.**

### هل يلزم مفتاح API؟

تستخدم واجهة IslamHouse API v3 المفتاح العام الموضح في التوثيق الرسمي. أما QuranEnc وHadeethEnc فلا يتطلبان مفتاح API خاصًا منفصلًا.

### هل يشمل ترخيص MIT ترجمات القرآن أو محتوى الحديث أو الكتب أو الصوتيات أو المرئيات أو مجموعات البيانات؟

لا. يطبق ترخيص MIT على الكود المصدري للمستودع والتوثيق والأمثلة التقنية الأصلية فقط. أما حقوق المحتوى فتخضع لشروط مستقلة.

### هل يمكن تعديل المحتوى؟

لا تغير معنى المادة الأصلية ولا تقدمها بصورة مضللة. ويمكن إجراء تنسيقات تقنية أو فهرسة أو بحث أو تخزين مؤقت أو تعديلات في طريقة العرض بشرط الحفاظ على النسبة إلى المصدر وسلامة المحتوى ومعناه.

### هل يمكنني استخدام المحتوى داخل تطبيق تجاري؟

يمكن السماح بالاستخدام التجاري أو المدعوم بالإيرادات إذا كانت الحقوق المرتبطة بالمحتوى تسمح بذلك. ولا يمنح هذا المستودع حقًا تجاريًا عامًا على جميع المواد.

### هل يمكن تخزين المحتوى دون اتصال بالإنترنت أو تضمينه داخل التطبيق؟

قد يكون ذلك مسموحًا حسب المادة وصاحب الحق. وإذا كان مشروعك يتضمن تخزين أو تضمين أو إعادة نشر أو إنشاء نسخة مرآة أو إعادة توزيع كمية كبيرة من المحتوى، فيجب التحقق من الشروط قبل الإطلاق.

### هل يمكن استخدام واجهات API في مساعد ذكاء اصطناعي أو Chatbot أو نظام RAG أو محرك بحث؟

نعم، هذه من حالات الاستخدام التقنية المدعومة، بشرط الالتزام بحقوق المحتوى الأصلي. ولا يمنح ترخيص المستودع تلقائيًا حق تدريب النماذج أو Fine-tuning أو إعادة توزيع مجموعات بيانات التدريب.

### هل النسبة إلى المصدر مطلوبة؟

نعم. احفظ اسم المنصة المصدر وبيانات المترجم والمؤلف والمراجع والناشر والقارئ والإصدار متى ما كانت متوفرة.

### ماذا لو كانت الترجمة أو الكتاب أو الملف الصوتي أو غيره مملوكًا لطرف ثالث؟

تظل الحقوق والشروط الخاصة بالطرف الثالث نافذة ومقدمة على الإرشادات العامة للمستودع.
