# 📌 الهدف

يخدم هذا المستودع **المطورين والباحثين والمؤسسات وفرق المنتجات حول العالم** الذين يحتاجون إلى نقطة مرجعية موحدة للوصول إلى محتوى إسلامي أصيل ومتعدد اللغات من خلال منصات وواجهات رسمية.

ويجمع الوصول إلى:

- **IslamHouse.com** ← الكتب، المقالات، الفتاوى، الصوتيات، المرئيات، المؤلفون، الناشرون، التصنيفات وغيرها من الموارد الإسلامية.
- **QuranEnc.com** ← ترجمات معاني القرآن، التفسير، بيانات السور والآيات، بيانات المترجم والإصدار.
- **HadeethEnc.com** ← ترجمات الأحاديث الموثقة، والشروح، والتصنيفات الموضوعية.

**الوصول إلى واجهات API مجاني.** كما نرحب بتنزيل المحتوى وإعادة نشره وطباعته وتوزيعه وتضمينه في التطبيقات والمشروعات التجارية وغير التجارية، دون حاجة إلى إذن مسبق ما دام الاستخدام ملتزمًا بسياسة المحتوى المنشورة في هذا الملف.

# 🎯 لماذا أُنشئت هذه البوابة؟

غالبًا ما يواجه المطورون أربع مشكلات رئيسية عند تطوير التطبيقات الإسلامية:

1. **تشتت المصادر** — بيانات القرآن والحديث والكتب والصوتيات والمواد متعددة اللغات موزعة على خدمات متعددة.
2. **جودة المصدر** — قد تفتقر مجموعات البيانات غير الرسمية إلى معلومات المصدر أو المترجم أو بيانات الإصدار.
3. **اكتشاف اللغات** — قد يصعب معرفة اللغات المدعومة بصورة موحدة ودقيقة.
4. **وضوح سياسة الاستخدام** — المطور يحتاج إلى معرفة ما المسموح به، وكيف يحفظ النص والمصدر وبيانات النسخة عند إعادة النشر.

توفر هذه البوابة نقطة مرجعية واحدة وسهلة للمطورين لاكتشاف الواجهات الرسمية، وأنواع المحتوى، ودليل اللغات المعتمدة، وإرشادات التكامل، ومعلومات الحقوق.

# 🌍 تغطية اللغات

يعتمد هذا المستودع **الدليل المعتمد المكون من 147 لغة** والمقدم من المشروع بوصفه المرجع الرسمي للغات.

> [!NOTE]
> يوضح الدليل التالي اللغات المعتمدة وبيانات ISO المستخدمة في المشروع. ولا يعني ذلك أن جميع المنصات أو جميع أنواع المحتوى متوفرة في جميع اللغات الـ147. يختلف التوفر الفعلي حسب المنصة ونوع المحتوى والترجمة والإصدار.

**حقول الدليل:**

- **الاسم الأصلي** — الاسم المعتمد باللغة الأصلية.
- **رمز ISO** — رمز اللغة المعتمد في الدليل.
- **معيار ISO** — إصدار معيار ISO 639 المستخدم للرمز.
- **الاسم العربي** — الاسم العربي المعتمد للغة.
- **الاسم الإنجليزي** — الاسم الإنجليزي المعتمد للغة.

- استغلال ندرة المادة في لغة أو بلد لفرض سعر مرتفع عليها.
- تقديم المادة المتاحة للنشر على أنها منتج حصري مرتفع القيمة.
- تحويل الإذن بالطباعة والتوزيع إلى وسيلة للاحتكار أو الاستغلال التجاري.

> **الهدف من البيع هو استدامة نشر المادة وإيصالها لمن يحتاجها، لا التكسب المبالغ فيه من العلم المتاح.**

إذا أعيد بيع المحتوى بأسعار مبالغ فيها بقصد التكسب وليس لتغطية التكلفة المعقولة واستدامة النشر، فيُعد ذلك استخدامًا خارج نطاق الإذن الممنوح بهذه السياسة، ويحق لنا التواصل مع البائع وطلب تصحيح السعر، أو تقديم شكوى إلى المتجر أو منصة النشر وطلب إزالة المنتج.

# 🛒 المتاجر الإلكترونية ومنصات النشر

يجوز عرض النسخ المسموح بها في المتاجر ومنصات التوزيع عند الالتزام بهذه السياسة، لكن قبول المتجر للمنتج لا يعني موافقتنا على طريقة نشره أو تسعيره أو بياناته.

وعند النشر عبر Amazon أو غيره يجب الالتزام مجتمعةً بـ:

**حفظ النص الأصلي + حفظ المصدر والبيانات + إبقاء الإصدار والنسخة + عدم إنشاء ISBN جديد + عدم الادعاء بحقوق حصرية + التسعير في حدود التكلفة المعقولة لغرض الاستدامة.**

وفي حال مخالفة هذه الشروط يحق لنا تقديم بلاغ رسمي وطلب إزالة المنتج أو تصحيح وضعه.

# ❓ الأسئلة الشائعة

### هل الوصول إلى واجهات API مجاني؟

نعم. الوصول إلى الواجهات مجاني، كما أن إعادة استخدام المحتوى متاحة وفق سياسة الاستخدام المنشورة في هذا الملف.

### هل يلزم مفتاح API؟

تستخدم واجهة IslamHouse API v3 المفتاح العام الموضح في التوثيق الرسمي. أما QuranEnc وHadeethEnc فلا يتطلبان مفتاح API خاصًا منفصلًا.

### هل أحتاج إلى طلب إذن قبل استخدام المحتوى؟

لا، ما دام الاستخدام ملتزمًا بهذه السياسة. ويمكن طلب خطاب تأكيد رسمي فقط إذا احتاجته جهة خارجية لأغراض التوثيق أو الامتثال.

### هل يمكن نشر المحتوى وطباعته؟

نعم. نرحب بالنشر والطباعة والتوزيع مع حفظ النص الأصلي والمصدر وبيانات النسخة والإصدار.

### هل يمكن استخدام المحتوى في تطبيق تجاري؟

نعم، ويجوز استخدامه في التطبيقات والمواقع والمشروعات التجارية وغير التجارية وفق هذه السياسة.

### هل يمكن تخزين المحتوى دون اتصال أو على خادم خاص؟

نعم، ويجوز التخزين المحلي والتخزين المؤقت والفهرسة والتضمين داخل التطبيقات، مع المحافظة على النص والمصدر والنسخة.

### هل يمكن تلخيص أو اختصار المادة؟

يمكن إنشاء تلخيص أو اختصار أو إعادة صياغة باعتبارها **عملًا مستقلًا** من إعداد صاحبها، لكن لا يجوز نسب النسخة المعدلة إلى IslamHouse أو QuranEnc أو HadeethEnc باعتبارها إصدارًا صادرًا منها، ولا استخدام عبارة «بتصرف» أو «بتصرف يسير» بطريقة توهم أن الموقع أقر النسخة المعدلة.

### هل يمكن تعديل ترجمة أو نص أصلي ثم إبقاؤه منسوبًا إلى الموقع؟

لا. إذا كانت لديك ملاحظة علمية أو لغوية، أرسلها إلى إدارة الموقع للمراجعة والتصحيح في النسخة الرسمية.

### هل يمكن استخدام المحتوى في AI أو RAG؟

نعم. يجوز استخدامه في البحث وRAG وEmbeddings والتدريب وFine-tuning والأدوات الذكية، بشرط عدم تقديم المخرجات المولدة أو المعدلة على أنها النص الأصلي الصادر عن مواقعنا.

### هل يمكن إصدار ISBN جديد للكتاب أو الترجمة المعاد نشرها؟

**لا.** لا يجوز استخراج ISBN جديد لمحتوى مأخوذ من مواقعنا، ولا تسجيله كطبعة أو إصدار أو ملكية جديدة باسم ناشر آخر.

### هل يمكن بيع النسخ المطبوعة؟

يجوز بيع النسخ المادية لتغطية التكاليف الفعلية والمعقولة والواضحة اللازمة للطباعة والتوزيع واستدامة النشر. أما المبالغة في السعر بقصد التكسب من المحتوى نفسه فمرفوضة وتقع خارج نطاق الإذن.

### ماذا يحدث عند انتهاك سياسة ISBN أو التسعير أو نسبة المحتوى؟

يحق لنا التواصل مع المخالف، وطلب التصحيح أو الإزالة، وتقديم بلاغ رسمي إلى المتجر أو منصة النشر أو الموزع. وقد تتخذ المنصة وفق سياساتها إجراءات إضافية تجاه المنتج أو الحساب.

### هل النسبة إلى المصدر مطلوبة؟

نعم. يجب ذكر المنصة المصدر بوضوح، والمحافظة على بيانات المؤلف أو المترجم أو المراجع أو الناشر أو القارئ ورقم الإصدار متى كانت موجودة.
